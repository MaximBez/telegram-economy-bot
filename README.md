# 🤑 Telegram Экономический Бот

Полноценный Telegram-бот экономики на **Python 3.11+ / aiogram 3 / aiosqlite**:
шахта с энергией, объекты с пассивным доходом, магазин материалов с тирами,
живой рынок с котировками, зелья, сундуки с джекпотами, 4 мини-игры,
ограбления, банк с процентами, топы, админ-панель и мини-игра **Ловец слов**.

Экономика щедрая и бесконечная: объекты и шахта улучшаются **без предела**,
баланс защищён потолком `1e300` — переполнений не бывает.

---

## 🚀 Быстрый старт (2 минуты)

```bash
# 1. Клонировать
git clone https://github.com/MaximBez/telegram-economy-bot.git
cd telegram-economy-bot

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Создать .env (см. .env.example)
#    Linux/macOS:
cp .env.example .env
#    Windows:
copy .env.example .env

# 4. Вписать в .env токен от @BotFather и свой Telegram ID
#    BOT_TOKEN=...
#    ADMIN_IDS=...

# 5. Запустить
python main.py
```

Больше ничего не нужно: база SQLite создаётся автоматически при первом запуске.

### Важно для групп (Ловец слов)

Чтобы бот видел обычные сообщения в группах и игра «Ловец слов» работала,
в @BotFather: `/mybots` → ваш бот → **Bot Settings → Group Privacy → Turn off**.

## 📖 Команды

### Основное
- `/start` — регистрация и меню-клавиатура
- `/баланс` (`/balance`) — наличные и банк
- `/профиль` (`/profile`) — полная статистика
- `/склад` — материалы, активы, зелья
- `/помощь` (`/help`) — все команды
- `/топ [слова]` — топ богачей / топ ловцов слов

Команды работают и со слэшем, и просто текстом (`баланс`, `копать`...).

### 🏢 Объекты (пассивный доход)
- `/объекты` — список объектов и накопленный доход
- `купить кафе 3` / `купить объект 1 5` — покупка (цена растёт +12% за штуку)
- `продать кафе 2` — продажа за 50% цены последнего купленного
- `собрать` — забрать доход (копится до 24 часов)

14 объектов: от Киоска (50 тыс → 3 тыс/ч) до Генератора чёрных дыр
(10 квадриллионов → 700 трлн/ч).

### ⛏ Шахта
- `/шахта` — уровень, энергия, требования к улучшению
- `копать` — деньги + материалы (энергия: 100 макс, +1 каждые 90 сек, копка 15)
- `улучшить шахту` — апгрейд за деньги + железо (**без предела уровня**)

### 🛒 Магазин и рынок
- `/магазин` — материалы с тирами 1–5 (Железо → Кристалл)
- `купить железо 2 10` — 10 шт железа **тира 2**; `купить железо 10` — тир 1
- `продать железо всё` — продать все тиры магазину за 60%
- `/рынок` — котировки Биткоина, Эфира, Золота, Нефти, Акций
  (меняются каждые 5 минут, случайное блуждание)
- `купить биткоин 0.5` / `продать биткоин всё` — торговля активами

### 🧪 Зелья
- `/зелья` — рецепты (деньги + материалы)
- `сварить удача 3` — варка до **20 шт за раз**
- `пить удача` — эффект: удача (+шансы в играх), сила (+ограбление),
  шахтёр (×2 добыча), щит (защита от ограбления),
  эликсиры богатства (+15% баланса мгновенно) и времени (сброс кулдаунов)

### 🎁 Сундуки
- `/сундук` — 5 сундуков: Обычный → Бесконечный
- `сундук редкий 5` — открыть до **50 за раз**, есть джекпоты (×6–×10)

### 🎲 Игры
- `монетка 10к` — орёл/решка ×2
- `кубик 1000` — бросок против бота ×2 (ничья — возврат)
- `казино 5млн` — слоты: пара ×1.4, джекпоты ×11/×33/×77
- `рулетка 1000 красное` — красное/чёрное ×2, зеро ×36

Ставки: от 100 до 1 квадриллиона. Форматы: `10к`, `2.5млн`, `3трлн`,
`1квнт`, `2e18`, `50%`, `всё`.

### 🕵️ Улица
- `грабить` (reply или `грабить @user`) — 45% шанс (+25% с зельем силы),
  кража 15% наличных жертвы; при провале штраф 10%. **Кулдаун — ровно 3 часа**
- `перевести @user 1млн` — перевод между игроками (мин. 100)
- `банк положить всё` / `банк снять 500к` — банк **+3% в час**

### 👑 Админ-панель (`/админ`)
```
/админ выдать <id|@user> <сумма>   — выдать деньги
/админ забрать <id|@user> <сумма>  — списать деньги
/админ установить <id|@user> <сумма> — задать баланс
/админ бан / разбан / сброс <id|@user>
/админ стата                       — статистика бота
/админ слово                       — запустить Ловца слов в чате
/админ рассылка <текст>            — сообщение всем игрокам
```

## 🔧 Технические детали

- **aiogram 3.x**, `DefaultBotProperties(parse_mode=HTML)` — современный API.
- **SQLite + WAL**: одиночный коннект, `busy_timeout`, ленивые вычисления
  (энергия, проценты банка, доход объектов, котировки) — ни одного таймера.
- **Атомарность**: все денежные операции — `BEGIN IMMEDIATE` под глобальным
  `asyncio.Lock`; операции игрока дополнительно под per-user lock (двойные
  клики не ломают баланс).
- **Формат чисел**: `1.23 млн`, `45.6 млрд`, `2.5 квнт`, `1e+45` — до `1e300`.
- **Парсер сумм**: русские и латинские суффиксы, проценты, научная запись, «всё».
- **Кулдауны/эффекты** хранятся в БД — переживают рестарт бота.

### Структура проекта
```
main.py            — точка входа, middleware, меню команд
config.py          — .env-конфиг, ADMIN_IDS, MAX_BALANCE

db_costs.py        — игровые константы и формулы
guards.py          — блокировки, транзакции, переводы, ставки
formatters.py      — формат чисел/времени, парсер сумм
filters.py         — фильтр команд (текст + /слэш)
handlers/
  admin.py         — админ-панель
  objects.py       — объекты, сбор дохода
  mines.py         — шахта
  market.py        — магазин, рынок, склад
  potions.py       — алхимия
  chests.py        — сундуки
  games.py         — игры
  social.py        — ограбления, переводы, банк, топы, помощь
  profile.py       — /start, баланс, профиль
  wordcatch.py     — Ловец слов (строго последний роутер)
```

### Балансировка (кратко)
- Объекты: цена +12% за экземпляр, доход окупается за ~16–20 часов.
- Шахта: находка `400–1200 × уровень^1.35`; улучшение `50к × уровень^2.1`.
- Игры: монетка 50/50 (с удачей 56%), слоты ~100% EV, рулетка 97.3% EV.
- Банк: +3%/час (доход копится максимум за сутки).
